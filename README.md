# Data Analysis for IoT
Repositori ini berisi materi lengkap perkuliahan, modul praktikum, dan kuis untuk mata kuliah **Data Analysis for IoT**.
Materi disusun untuk 16 pekan pertemuan (termasuk UTS dan UAS), mencakup:
- Konsep dasar IoT dan Edge Analytics
- Pre-processing data sensor (Outliers, Missing Values)
- MQTT Protocol (Publisher & Subscriber)
- Time-Series Database (InfluxDB)
- Visualisasi Data (Grafana & Dashboarding)
- Machine Learning (Forecasting & Anomaly Detection)
- Integrasi Pipeline End-to-End & Project-Based Learning

Semua materi dapat diakses di dalam folder masing-masing `Pekan_01` hingga `Pekan_16`.
