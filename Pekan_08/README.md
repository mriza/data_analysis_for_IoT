# Pekan 8: Evaluasi Tengah Semester (UTS)

> [!IMPORTANT]
> **PEMBERITAHUAN AKADEMIK PENTING:**  
> **Pekan 8 adalah pekan khusus pelaksanaan EVALUASI TENGAH SEMESTER (UTS)** sesuai dengan Rencana Pembelajaran Semester (RPS) dan Distribusi Tugas Perkuliahan.  
> **TIDAK ADA penyampaian materi perkuliahan baru pada Pekan 8.** Seluruh kegiatan pada pekan ini difokuskan untuk menguji dan mengevaluasi penguasaan kompetensi teori maupun keterampilan praktikum mahasiswa terhadap materi **Pekan 1 hingga Pekan 7** (Bobot Penilaian UTS: **15% – 25%** dari Nilai Akhir Mata Kuliah).
