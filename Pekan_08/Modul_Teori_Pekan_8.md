# Pekan 8: Evaluasi Tengah Semester (UTS) (Teori)

## Materi Pertemuan 1 - 7
Ujian Tulis/Studi Kasus akan mengukur kompetensi analitik Anda secara komprehensif.

### Kisi-kisi UTS:
1. Menjelaskan mengapa dataset dari sensor lingkungan IoT memiliki tingkat *noise* yang tinggi dan rentan *missing values*.
2. Membedakan karakteristik arsitektur Cloud, Fog, dan Edge secara tepat berdasarkan studi kasus industri (kapan harus menggunakan arsitektur yang mana).
3. Mendemonstrasikan pemahaman dasar penambalan data (imputasi), *moving average*, dan pendeteksian anomali menggunakan konsep *Interquartile Range*.
4. Menjelaskan secara ringkas konsep *Tiny Machine Learning*.
